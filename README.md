# 星律舞团 BeatStar

网页版 3D 节奏舞蹈游戏：方向键输入箭头序列、空格踩点，舞者随判定在霓虹舞台上起舞。

## 运行

```bash
npm install
npm run dev      # 开发模式，打开终端里显示的地址
npm run build    # 打包到 dist/，可部署到任意静态服务器
```

## 玩法

- **经典模式**：在光标到达右侧圆圈前依次输入箭头，然后在光标碰到圆圈时按空格。红色箭头要按反方向，按错会清空输入。最后一回合是 FINISH，成功会触发终结舞步。
- **节奏模式**：音符从右向左滚动，到达圆圈时按对应键；金色胶囊是空格，带尾巴的要按住。
- 按键：方向键 / WASD / 小键盘 8246，空格，Esc 暂停。
- 判定窗口：PERFECT ±45ms，GREAT ±90ms，COOL ±135ms，BAD ±180ms。设置里可以做延迟自动校准。

## 结构

- `src/audio/`：合成器乐器、编曲器（分段并行离线渲染）、播放器与高精度歌曲时钟
- `src/scene/`：舞台（平面反射、LED 屏、光束、粒子、镜头导演）、程序化建模的舞者、舞蹈动作库（腿部 IK）
- `src/game/`：谱面生成、判定与计分
- `src/ui/`：HUD（Canvas 2D）与界面样式
